# 模型分歧的追加拆解

明确属于看到主审计结果后的探索性检查；不是预先独立验证。所有参数沿用主审计。

seed_spread：同架构三个训练种子的分歧，需要3模型；architecture_gap：两个架构各三种子均值的差，需要6模型。
disagreement：两者组合，需要6模型。点预测中心保持原单模型，不采用ensemble均值替代。
绝对误差检查依然控制预测寿命，但不使用相对误差分母，用于检查信号是否仅由共同分母驱动。

下表为历史池按实验条件5折、每折全部风险训练样本的结果。正值表示相对仅寿命对照改善。

| 模型 | 分歧信息 | 相对误差损失改善/胜数 | 大误差Brier改善/胜数 | 绝对误差损失改善/胜数 |
|---|---|---:|---:|---:|
| CPLSTM | architecture_gap | +10.0% / 9/9 | +10.6% / 9/9 | +3.3% / 8/9 |
| CPLSTM | disagreement | +10.3% / 9/9 | +9.6% / 9/9 | +2.6% / 7/9 |
| CPLSTM | seed_spread | +1.9% / 4/9 | +3.5% / 5/9 | -0.1% / 4/9 |
| CPMLP | architecture_gap | +6.3% / 8/9 | +7.1% / 8/9 | +2.4% / 6/9 |
| CPMLP | disagreement | +6.7% / 6/9 | +7.4% / 7/9 | +1.8% / 6/9 |
| CPMLP | seed_spread | +3.6% / 5/9 | +5.1% / 4/9 | +0.4% / 4/9 |

主审计中life和disagreement的MSE、Brier、AUC已逐项重算一致。所有模式与主设置结果见metrics.csv，逐电芯预测见predictions.csv。
这些结果不证明最佳距离已确定，不证明单种子或单个跨架构差值也能复现，不证明90%条件分位数可准确估计。
