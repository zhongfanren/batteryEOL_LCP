# ISU-ILCC 稳定性与曲线信息增益实验（2026-10-28）

18/18设置已于13:06完成，约85分钟，无失败或超时。独立复算与完整研究解读见 [analysis_review_20261028/ANALYSIS.md](analysis_review_20261028/ANALYSIS.md)。

本批次回答两个问题：此前的尺度 CP 收益是否依赖某个训练种子或电芯划分；控制预测寿命带来的误差尺度以后，早期曲线表示能否带来额外信息，帮助局部校准归一化残差。

设计固定为三次不分层电芯划分（种子20261026、20261028、20261029），每次97 train /20 dev /61 calibration /61 test；每次划分训练种子2021、42、2024，模型CPMLP、CPLSTM。共18个预测器设置，原划分seed2021的两个模型直接复用，共新增16次拟合。架构、超参数、dev T=100 MAPE早停与上轮一致。新拟合隔离预处理缓存对随机数流的影响；复用的两次历史拟合沿用其原始随机数过程，不能宣称与新增训练逐位完全一致。

冻结模型后导出每块电芯T=100的编码器表示。仅用97块训练电芯拟合3维白化PCA，开发、校准、测试只作变换，不用它们拟合PCA。重新前向的预测必须与原冻结CSV一致；实际CP比较仍保留CSV内的原值。既有模型、冻结预测和首轮区间报告保留。

对照全部报告：普通Split CP；直接寿命尺度CP；开发集拟合的预测值尺度CP；预测值加倍率尺度CP；预测值加曲线表示尺度CP。局部方法对**除以预测值尺度函数后的残差**做RLCP，分别使用预测值距离、预测值加曲线表示距离。标准化坐标中的高斯带宽1.5与3作为固定敏感性设置；不按test挑选带宽。开发尺度估计使用固定h=1.5的核回归，只有20块开发样本，这是明确局限。

除了各次拟合原本的61块test，还对同一冻结预测器未参与训练/开发的122块电芯做200次61/61校准/测试随机重分。预测器、PCA、开发尺度和诊断阈值始终冻结。此部分衡量校准/测试分配敏感性；反复使用同一批电芯，不能算200个独立数据集，也不是新的未见测试。

本轮附加风险分组的含义是“去除预测寿命尺度后的残差风险”：以开发集留一尺度计算归一化误差，再由开发曲线邻居估计风险，以开发集留一风险的三分位数定低/中/高。它与上轮“绝对周期误差风险组”含义不同，结果不能混在一起比较。分组仅用于诊断，不单独校准各组。

主要判断是每个种子/划分中的配对覆盖、平均宽度、interval score差异及无穷区间数。只有在合理覆盖下、多个设置中出现重复的额外收益，才支持继续发展曲线距离。曲线尺度CP改善不自动等于LCP改善；带宽敏感或仅一次较好的结果也不足以支持稳定贡献。全部预定方法和负结果一起保留，不根据历史测试表现再搜索参数。

## 运行与查看

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -NoExit -File D:\Battery-LCP\simple_cptransformer_cp\batterylife_main_table\start_isu_stability.ps1
```

- `plan.json`：运行前冻结的假设、方法、种子、代码指纹和任务清单。
- `state.json`：总队列状态、当前任务与PID；单任务细节见日志及该训练的progress.json。
- `analysis/<任务名>/console.log`：训练及分析的终端输出。
- `analysis/<任务名>/features.npz`：固定预测、编码器表示和逐电芯ID。
- `analysis/<任务名>/resplit_metrics.csv`：原test及200次重分的逐方法指标。
- `analysis/<任务名>/original_test_intervals.csv`：该模型原test的逐电芯半径和新风险组。
- `summary.csv`、`SUMMARY.md`：每完成一项任务自动更新；配对差异以预测值尺度CP为基线。

总队列最多运行3小时，单任务最多30分钟，剩余预算不足时保留已完成任务并标为`finished_partial`。这两个限制是资源上限，不能保证所有拟合完成；若任务提前结束，不为填满时间追加试验。中断训练后脚本不覆盖已有训练文件，重新开始需先核查进程和保存的阶段结果。

本轮用户已授权在外出期间运行约2到3小时实验。可见终端运行后，无需AI持续轮询。历史测试暴露、重复使用电芯及小样本限制仍适用，结论为探索性。
