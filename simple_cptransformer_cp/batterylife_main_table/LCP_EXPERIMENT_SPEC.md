# LCP 开始改进前的共同定义（2026-10-28）

这份说明固定术语与当前实验对象，不代表新增方法已经运行。研究问题仍是：在合理覆盖下，让电芯寿命区间适应可提前识别的预测风险，并检验局部化是否提供超出简单尺度调整的价值。

2026-11-04更新：当前研究入口为`../RESEARCH_START_HERE.md`，批次总账为`../EXPERIMENT_INDEX.md`。分数×局部性第一轮已完成，见`score_locality_20261104/BRIEF.md`；下面保留通用定义。

方法设计分成三层：选择分数、定义局部性、采用有相应覆盖依据的阈值校正/随机化构造。不能把“任意权重+固定90%分位数”直接视为有Guan保证的LCP。当前新实验用Hore–Barber Gaussian RLCP（测试∞质量保留），旧MATR basic阈值图另作历史诊断。

尺度CP与LCP可以组合；同分数的全局/局部对照是局部性增益的判断依据。尺度函数必须在测试真实寿命未知时可计算；宽度随尺度变化不自动说明尺度反映真实难度。

用户在2026-10-28明确选择横向任务：固定观测时点（当前T100），对不同新电芯预测寿命区间；不研究随运行过程更新区间。此前讨论的纵向/动态任务只是概念辨析，不加入当前研究范围。“风险适应”是横向设定下的方法评价方向，不要求一定先训练独立难度模型才能做LCP。

## 1. 简单寿命尺度 CP

它是标准化分数 split CP 的一种简单基线。本项目的“简单寿命尺度”是便于交流的描述性名称，不把它当作新算法或原论文的固定专名。报告中的实现名为 `relative_cp`。

设冻结预测器给出的非负寿命预测为 f(x)，尺度 s(x)=max(1,f(x))。在校准电芯上计算 R_i=|Y_i-f(X_i)|/s(X_i)，取有限样本修正的90%分位数q；61块校准电芯对应排序后的第56个分数。测试区间为 [max(0,f(x)-q*s(x)), f(x)+q*s(x)]。

例如校准得到q=0.2时，预测寿命500周期的半径为100周期，预测寿命2000周期的半径为400周期。q由校准数据确定，不是人工固定为0.2。分母用预测寿命，因此新电芯在未知真实寿命时也可计算。它与用真实寿命作分母的MAPE不同。

对照关系：

| 方法/实现名 | 校准分数 | 测试区间半径 |
|---|---|---|
| 普通Split CP / `split_cp` | 绝对误差 | 所有电芯相同的全局q |
| 简单寿命尺度CP / `relative_cp` | 绝对误差 / max(1,预测寿命) | q乘预测寿命尺度 |
| 开发集拟合寿命尺度CP / `prediction_scale_cp` | 绝对误差 / 开发集拟合的误差尺度 | q乘该误差尺度 |

以上方法都可具有变化宽度；变化宽度本身不证明进行了有效局部校准。接下来的LCP应检验改变“哪些校准残差对当前电芯更相关”是否带来额外收益。若采用尺度标准化分数，应明确选择哪个尺度，对照方法保持相同分数，避免同时换分数和距离导致归因不清。

标准化分数与尺度区间的先例见 [Lei等，§5.2](https://arxiv.org/html/1604.04173#S5.SS2)。固定的正尺度函数无需保证误差真的与寿命成比例，split CP的边际覆盖解释仍取决于校准/测试交换性和评分函数冻结；效率及组覆盖可能不好。

## 2. 开发集与校准集

Development set（dev）通常对应机器学习中的validation set，用来选择模型、超参数及早停，不是本项目新造的概念。参见 [scikit-learn模型选择说明](https://scikit-learn.org/stable/modules/cross_validation.html)。本项目额外用开发残差拟合辅助误差尺度/风险函数，这是具体的建模选择，不是所有validation set都必须承担的工作。

| 当前电芯数 | 角色 | 当前用途 |
|---:|---|---|
| 97 | train | 拟合点预测器及训练侧预处理 |
| 20 | dev | 选epoch/预测器，拟合或选择辅助尺度、距离规则 |
| 61 | calibration | 方法和分数冻结后，计算最终校准分位数 |
| 61 | test | 评价点预测和区间；历史标签已被查看，当前仅作探索性验证 |

从split CP的分工看，train+dev这117块都属于建模侧，61块calibration才是独立的最终分数校准侧。四份划分不是所有CP方法必须采用的格式；本项目把建模工作再拆成两份便于控制过拟合。若用校准标签反复选距离或调参，再沿用普通split CP的解释，需要另留最终校准集或采用相应有效的构造，不能继续把原校准集视为未使用过。

## 3. ISU-ILCC的239块是怎样来的

本地240个ISU-ILCC电芯文件与240个寿命标签键，恰好覆盖BatteryLife官方划分列出的240块电芯。原T=100加载器要求EOL>100并可产生100个有效前缀。

唯一未进入合格池的是 `ISU-ILCC_G40C3.pkl`：发布寿命标签16，原加载器记录可用前缀数0。其余239块全部入选，然后对按名称排序的电芯ID用seed20261026一次随机打乱，依次分成97/20/61/61。没有按曲线相似性、预测误差或区间表现筛出239块。

因此目标总体是满足第100周期任务资格的电芯，包含“活到该观测时刻”的条件。早期失效电芯不属于本次T=100预测任务。100个前缀仍只对应一块独立电芯，不能把它们当100个独立校准样本。

旧候选清单中的“no label-based filtering”只应理解为没有任务资格之外的标签/误差筛选；其字面表述不完整。资格核查见 `protocol_candidates/ISU_ILCC_CANDIDATE.md`。保留冻结JSON的原始字节与模型指纹。

## 4. 能否按相似曲线扩充

可以尝试，但从239块内部筛选只会更少。更大的候选需要来自其他来源；目前本地联合T=100合格池共823块，筛选后是否能得到多于239块的可解释总体，需要实际盘点，不能预先承诺。

一个可审验的方案是：先确定允许混合的电芯体系和标签口径；用训练/开发侧确定曲线归一化、表示与固定相似阈值；只根据前100周期的信息逐块决定入选；冻结电芯清单，再按电芯划分校准与测试。评价电芯不能参与表示/阈值选择或被基于其误差筛选。由现有预测器生成表示时，其训练与选型所用117块电芯继续留在建模侧。

相似形状需要结合材料、电压范围、容量归一化、实际协议和标签定义检查；曲线相近不等于误差分布相同，更不自动证明统计交换性。若校准和测试都来自同一个预定筛选总体，可以研究该总体下的覆盖；把其他来源只加到校准集、测试仍只用ISU，需要另外的迁移假设/方法。

如果新增电芯只进入新的校准与测试总体，且与训练/开发隔离，预测器可保持冻结；如果把新增电芯用于训练，就需要重新训练预测器。扩大数据总体后的结果应另列版本，不能与原239块上的方法变化混为一项改进。
