## 运行内容与上限

- 仅原train97内5折，每个外折分别训练CPMLP和CPLSTM，共10个辅助任务。
- 每任务先在约61块内训练、约16块内部验证上选epoch；然后从头在约77块上按选定轮数重训，预测约20块外折电芯。外折标签不参与梯度、标准化或早停。
- 保留原1..100周期前缀训练；外折只导出T100一次预测。100个前缀仍是一块电芯。
- 原dev20、cal61、test61不参与辅助训练。得到97块训练电芯的OOF误差后，风险模型在OOF97或原dev20上拟合，最终CP分位数仍只用当前61块校准电芯。
- 每任务内部最多30 epoch、patience6；单任务最多20分钟，整个辅助训练队列最多90分钟。超时或失败会保存状态并停止，不会把未完成冒充完成。
- 预计约30–60分钟，受早停与GPU速度影响。结束后自动评估18种预设构造并写简报；无需AI持续查看日志。

## 本轮如何保证可比较

交叉拟合只用每个架构一个种子，查询侧也用原seed2024的一对预测器计算分歧；之前六模型分歧尺度另列强对照。点预测中心仍为原单模型。

误差模型保持低容量：log预测寿命、其二次项、log(1＋相对架构分歧)，固定正则化。比较log误差平均趋势回归与90%分位数回归；OOF寿命单独回归作分歧增量对照。

LCP使用一维寿命距离或一维学习到的尾部风险距离，比较相同校准分数，h=3/6全报告，测试权重的无穷原子保留。原61块test与200次固定池重分分开报告，不因某次结果好就换配置。

辅助模型训练规模约77，主模型97，误差分布不一定相同；本轮会记录这种偏差，而不是把OOF误差直接当最终模型的校准误差。97个OOF预测来自相互重叠的训练集，也不能当97个独立拟合实验。历史测试标签已经查看，本轮仍属探索。
