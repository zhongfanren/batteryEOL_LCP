# 从MATR到ISU：研究问题、已有证据和仍缺少的突破

截至2026-10-28。本文用于整体理解与讨论，不启动新实验。旧数据、预测器、脚本与结果保留原样。

**当前判断：有正面进展，主要是简单尺度适应的重复证据、模型分歧的风险线索，以及更充分的训练侧误差监督；尚未证明可学习LCP稳定超过强简单基线。ISU与MATR不同，不能用绝对宽度或点预测误差直接判断新方法比旧方法更好。**

**1. 我们研究什么，哪些变化没有改变主线**

根据前100周期预测电芯寿命，在合理总体覆盖和可接受宽度成本下，让区间适应可提前识别的预测风险，尤其减少困难区域的漏覆盖。进一步问：局部校准是否提供超出简单尺度调整的价值？

“难”应指在提前可观察的信息下，预测误差更容易较大、尤其尾部更大；不是事后看到一次大误差就断定这块电芯事前必然难，也不是长寿命本身就等于难。理想对称90%半径是给定可用信息时绝对预测误差的90%分位数。实际只有每块电芯一次结果，需依靠可提前定义的群体、重复实验和尾部损失间接检验，不能逐块观测其真实误差分布。

可以用一个表达式理解路线：区间半径 = 误差尺度 s(x) × 校准系数 q(x)，区间以固定预测器 f(x) 为中心。

| 方法 | 尺度s(x) | 校准系数q(x) | 回答的问题 |
|---|---|---|---|
| 普通Split CP | 1 | 全体共同的q | 全局误差多大 |
| 尺度归一化CP | 预测寿命、分歧或学到的尺度 | 全体共同的q | 是否应按电芯调整误差量级 |
| LCP/RLCP | 可保持同一个尺度 | 按相关校准电芯的残差局部确定 | 哪些校准残差与当前电芯更相关 |

因此，“区间宽度会变化”不是LCP成功的充分证据。我们目前主要在s(x)上有正面结果，q(x)的局部化增量仍没有稳定证据。分组主要用于检查资源分配和漏覆盖，当前不等于按组实施校准，也没有每组90%的自动保证。

**2. 旧MATR实验已经得到什么**

旧主线是MATR＋CPTransformer，包括固定RBF、六组特征距离、可学习距离、Hopfield、频域、自监督迁移和ensemble。它们不是全部无效：

- 三种子ensemble曾减少点预测误差，模型分歧也提供过一定风险信号；但改善点预测中心不等于区间学习一定改善。
- 在一批MATR训练侧五折、三种子ensemble实验中，普通Split CP与固定六组RBF覆盖均90.20%；宽度617.2→597.9周期，interval score974.4→944.1。固定六组距离有小幅聚合收益。
- 同批可学习六组距离score935.2，相对固定六组944.1只改善约0.94%，逐折不稳定，主要改善来自一个困难折；不能据此认定学距离稳定更好。
- Hopfield、频域和冻结自监督表示未稳定超过简单固定特征；HUST重建预训练改善过初始化，但没有可靠地产生更好的误差相似性。
- 某次MATR官方test上的固定RBF结果很亮眼，但没有在开发期稳定复现，且test已查看，不能作为最终胜利。

这说明：**MATR已有“局部方法可能有用”的迹象，缺少的是超过简单对照的稳定、可解释收益。** 旧报告与最新报告没有推翻彼此，实验设定不同，不能拼成一条单调改进的曲线。

旧数字来源：[2026-09-30总结](RESEARCH_PROGRESS_SUMMARY_20260930.md)、[对应原始汇总](learnable_localizers/runs_grouped_metric_ensemble/20260930_222411_481781/summary.json)。旧basic weighted LCP诊断没有实现当前Gaussian RLCP的同一完整构造，经验收益也不能直接作同等理论有效性的比较。

**3. BatteryLife复现、混合数据与迁移尝试起了什么作用**

完成多个原始架构的本机训练，让我们不再只能依赖一个CPTransformer，留下了可冻结预测器和模型分歧信息。混合Li-ion论文口径的多前缀指标、MATR单电芯T100指标、ISU T100指标是不同任务口径；数值相近不能证明同样性能，不能用它们直接证明LCP进步。

完全不含MATR训练的混合预测器转到MATR时表现差，说明“外域训练、MATR只校准测试”在当时预测器上不够实用。后来转向混合总体和单来源ISU，是为了明确可研究的目标总体与风险异质性。混合来源本身不自动破坏CP交换性；关键是校准与测试是否来自同一事先定义的目标总体，而不是只把其他来源残差加进校准。

按协议/曲线寻找更大且可解释的总体仍是候选工作，没有构建并验证一个已经优于当前ISU的新扩大数据集。当前ISU239不是相似性筛选：本地240块中一块EOL16，未通过T100资格，其余全部进入候选池。

**4. 相比MATR，目前平台确实改善了什么**

| 环节 | 过去MATR的典型设置 | 当前ISU设置及改善 | 仍有的限制 |
|---|---|---|---|
| 总电芯数 | 169 | 239个T100合格电芯 | 不是大型数据，也不是相同材料/分布 |
| 校准/测试 | 官方34/33；部分开发CV每折约20/20 | 当前固定61/61 | 局部化后有效样本量仍会下降 |
| 稳定性 | 多折、多模型种子的旧实验 | 3划分×3种子×2架构，共18冻结设置 | 相互重叠，不是18独立数据集 |
| 风险参考误差 | 部分设置约20块，旧阶段也已有交叉拟合探索 | 本轮得到97块训练电芯各自的OOF误差、两架构成对预测 | 不是首次发明交叉拟合，不是新增97块物理数据 |
| 对照与归因 | 容易同时改变表示、距离、预测器 | 明确区分寿命尺度、分歧尺度、学习尺度和同分数局部化 | 仍需真正超越这些强基线 |
| 局部化实现 | 多数旧实验为basic weighted quantile诊断 | 实现Gaussian RLCP随机中心及测试点+∞权重 | 有效构造不保证有限、紧或有用 |

当前主平台是97 train / 20 dev / 61 cal / 61 test，CPMLP seed2024为主预测器（按原dev选择），CPLSTM固定复核。不是把原ISU测试表现最好的模型挑作主模型。

200次重分只重新分配同一122块历史电芯的cal/test角色。它有助于观察划分敏感性，既不增加电芯数，也不消除历史标签已看过的事实。

**5. 目前最实质的正面结果：简单尺度适应**

下表全部来自ISU CPMLP的同一批9个冻结设置。先每设置平均200次重分，再对9设置等权平均；不与MATR绝对数字横比。

| 方法 | 覆盖 | 宽度/周期 | Interval score |
|---|---:|---:|---:|
| 普通Split CP | 90.18% | 1179.9 | 2171.9 |
| 直接寿命尺度CP | 90.27% | 1117.4 | 1555.3 |
| dev拟合寿命尺度CP | 90.18% | 1021.9 | 1778.9 |
| 寿命＋六模型分歧尺度CP | 90.32% | 1101.9 | 1512.4 |

直接寿命尺度s=max(1,预测寿命)，不学习误差；dev拟合寿命尺度用开发误差回归；分歧尺度s=max(1,预测寿命)+|三个CPMLP均值−三个CPLSTM均值|。三者不可混称。

- dev寿命尺度比Split更窄，CPMLP宽度减少13.4%、CPLSTM10.4%，两架构各9/9设置宽度和score均改善。直接寿命尺度的score反而更低，说明最窄的方法不一定最好。
- 分歧尺度比直接寿命尺度的平均score进一步降低约2.8%/4.9%，两架构各9/9设置score改善；宽度CPMLP7/9、CPLSTM9/9改善。它是小幅、一致的探索性线索，不是独立统计显著性结论或新LCP算法。
- 平均宽度始终有意义，但需连同覆盖、漏覆盖严重程度（interval score）和风险组表现看。score越低越好，它综合宽度和漏覆盖惩罚，并不等于只看宽度。

来源：[尺度稳定性分析](batterylife_main_table/isu_stability_20261028/analysis_review_20261028/ANALYSIS.md)、[分歧尺度与距离试验](batterylife_main_table/isu_stability_20261028/disagreement_cp_20261028/BRIEF.md)。

**6. 在“难电芯更宽、易电芯更窄”上有没有实质进展**

有局部迹象，但未完成目标。六模型分歧组由dev的可提前观察分歧阈值定义，不按test真实误差分组。在此前18设置批次，高分歧组实际误差更大；加入分歧尺度后，高组更宽、低组更窄：

| 预测器 | 低分歧覆盖：原→加分歧 | 高分歧覆盖：原→加分歧 |
|---|---:|---:|
| CPMLP | 96.2%→94.2% | 81.8%→84.3% |
| CPLSTM | 97.0%→95.7% | 80.8%→82.8% |

这比单独说“平均宽度降低”更接近我们的研究问题：区间有向风险较高区域重新分配的迹象。但高组仍约83–84%，原主test高分歧组两种方法都只覆盖15/20=75%；原test总体覆盖甚至88.5%→86.9%。所以还不能称为成功。

分歧度只是风险代理，不是电芯固有难度的真值。不同阶段的绝对误差风险组、归一化风险组、六模型分歧组、单模型对分歧组定义不同，组覆盖数字不能作为同一群体的连续提升记录。

**7. 最新OOF97实验为什么没有延续成LCP收益**

首先，训练侧误差来源得到了改善。原dev20里两架构都没有>50%相对误差实例，OOF97里有7/9个。每块外折电芯均未参与相应模型的拟合、标准化或早停，最终CP仍用原61块校准。

其次，风险信号没有因此自动变强。单种子模型对的平均误差回归，没有稳定超过此前六模型分歧尺度；对历史池相对误差的风险排序相关也很弱。辅助模型每折77/78块训练，主模型97块，且使用的分歧描述也从六模型变成一对；这不是只改变误差样本数量的完美受控实验。

最后，两个OOF 90%分位数回归在固定L1alpha=.05下特征系数全0。相对风险成为常数，距离全部相同，尺度常数又被最终校准抵消，于是所有学习尾部LCP等同简单寿命尺度CP。NaN相关和全部电芯进入一个风险组均是这个退化的结果。

**因此，不能说本轮学出了有效LCP，也不能把这轮结果解释为学距离一定无效。** 本轮自动简报没有解释退化，是复核报告补出的重要限制。之后每次应先检查预测风险是否有变化、是否形成非空且可解释的组，再解释区间指标。

来源：[最新独立复核](batterylife_main_table/isu_crossfit_risk_20261028/analysis_review/ANALYSIS.md)。OOF、辅助模型和冻结预测均可复用，下一步检查风险模型无需重跑这批GPU训练。

**8. 现在已经回答与尚未回答的问题**

| 问题 | 当前判断 |
|---|---|
| 仅追求更强点预测器是否足以解决课题 | 点预测有帮助，但不能替代风险和局部区间研究；MATR与ISU性能不直接横比 |
| 等宽区间是否足够 | ISU证据支持简单尺度适应有实际价值 |
| 除预测寿命外是否有可利用信息 | 六模型跨架构分歧有候选信号，单种子对及学习迁移较弱，尚未普遍确认 |
| 区间能否向困难区域分配 | 已有小幅正面线索，但风险组漏覆盖与资源转移仍明显 |
| 曲线相似是否等于误差相似 | 当前实验不支持直接等同，复杂表示未稳定胜出 |
| 更多诚实误差是否自动解决问题 | 不会；样本来源改善，模型、特征和误差迁移仍是瓶颈 |
| 当前LCP是否稳定优于简单尺度CP | 尚未证明；最新尾部学习距离退化，未完成有效检验 |
| 是否已有可主张的方法创新 | 尚无足够证据；现有收益主要是已有CP框架的尺度构造及实证线索 |
| 是否已经证明课题做不出来 | 没有；但也不能把流程完善代替方法贡献 |

**9. 接下来最值得解决的方向，按优先级排列**

第一，检验现有OOF训练侧能否学到可迁移的尾部差异。先检查正则化、非退化与训练侧稳定性，不能按历史cal/test最优挑参数。仅让系数非零远远不够，还需要风险排序/尾部损失的改善证据。

第二，分清“信息不够”与“表达方式不对”。如果单模型对不稳定，要检查它与原六模型分歧的差别，及OOF辅助预测器与主预测器的误差迁移，不能一律解释为样本还太少。对曲线的进一步探索也必须回答是否增加了寿命和分歧之外的信息。

第三，在有非恒定、可解释的风险后，做同分数的全局/局部对照。若学尺度已解释全部收益，而LCP只增加方差或无穷区间，应如实收缩主张，不能为了题目带LCP而把尺度收益算成距离创新。

第四，方法冻结后到MATR及其他已有冻结设置检查一致性，并最终寻找更独立的验证数据或协议。MATR历史test也已查看，只能称跨数据集复核，不能称全新未见测试。扩大曲线筛选总体和GWCP暂不作为当前主要工作。

若在合理、有限的训练侧诊断后仍没有稳定尾部信号，应考虑调整研究主张，而不是无限更换网络和kernel：例如转向解释电池小样本局部校准何时有用、何时被尺度效应和样本离散限制。但负结果本身不自动构成充分的论文贡献，仍需系统证据与清楚边界。

**10. 当前最准确的一段汇报**

我们围绕固定前100周期的电池寿命预测，研究能否利用可提前获得的信息分配预测区间宽度。MATR阶段已经发现简单固定距离和ensemble的局部正面线索，但可学习距离未稳定超过固定距离。ISU阶段在更大的校准/测试池和多设置下，得到了简单寿命尺度及模型分歧尺度的重复改进，也发现总体90%覆盖仍掩盖高风险区域漏覆盖。最新交叉拟合补充了训练侧诚实误差，但学习尺度尚未稳定胜过简单分歧尺度，尾部学习距离则因常数退化而没有完成有效检验。目前应聚焦可迁移尾部风险和局部化增量，而不是继续比预测器排行榜或直接增加网络复杂度。
